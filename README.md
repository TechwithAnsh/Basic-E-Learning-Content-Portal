# E-Learning Portal – All Classes

A school-focused e-learning website for all classes, with Hindi, English, Mathematics, Science and Social Studies (SST).

## Run
1. Extract this ZIP and open the `elearning_portal` folder in VS Code.
2. Open the terminal in that folder.
3. Run `npm install`
4. Run `npm start`
5. Open http://localhost:3000

## Subjects
- Hindi – Classes 1–12
- English – Classes 1–12
- Mathematics – Classes 1–12
- Science – Classes 1–12
- Social Studies (SST) – Classes 1–12

The portal is intended for all school classes. Specific chapters, videos, notes and quizzes should be added class-wise by teachers to match the school's curriculum.

## Backend
- Student and teacher registration/login
- Password hashing and session-based authentication
- Teacher course creation and deletion
- Student enrolment and progress tracking
- Quiz attempt storage
- Persistent local JSON data file (`elearningportal-data.json`)

## Important
This is a local academic demo, not a production-ready school platform. Teacher registration is open for demonstration; real school deployment should use administrator-approved teacher accounts and additional security controls.
